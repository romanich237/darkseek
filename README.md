# Darkseek

Локальный мессенджер на Node.js и SQLite. Профили, сеансы, диалоги и сообщения сохраняются в файле users.db.

## Запуск

Установите Node.js 24 или новее. Скачайте репозиторий и выполните в его каталоге команду

```sh
node server.js
```

Откройте http://127.0.0.1:3000. Зависимости устанавливать не требуется.

Адрес, порт и путь базы задаются в config.json. По умолчанию сервер доступен только на этом компьютере. Для проверки двух профилей используйте разные браузеры или приватное окно.

Создайте профиль и сохраните личный ключ. Передайте собеседнику публичный ID из настроек профиля. История обновляется каждые шесть секунд. Интерфейс показывает последние 100 сообщений, остальные остаются в базе. Сообщения хранятся в открытом виде.

## Обновления

Для обновлений нужна копия, полученная через git clone, и установленный Git. check-updates.bat проверяет новые коммиты в отслеживаемой ветке GitHub. update.bat устанавливает обновления при отсутствии локальных изменений и расхождения веток. Затем перезапустите сервер. Проверить и установить обновления также можно командами npm run update:check и npm run update.

База users.db создаётся при первом запуске и исключена из Git. Для резервного копирования остановите сервер и скопируйте users.db. При обновлении старая локальная база data/darkseek.sqlite автоматически копируется в users.db, если users.db ещё отсутствует.

Существующие данные облачной версии автоматически в локальную базу не переносятся.
