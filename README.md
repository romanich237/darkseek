# Darkseek

Darkseek — прототип анонимного мессенджера с входом по личному ключу. Для поиска собеседника используется публичный ID.

## Что можно попробовать

- Войти по демонстрационному ключу `V7Q9 N4RX 2K8M T6WP`.
- Открыть диалог из списка или найти его по публичному ID, например `ghost_7a2f`.
- Написать сообщение и переключиться между диалогами.

Сообщения хранятся в памяти браузера до перезагрузки страницы. Вход по ключу и переписка работают в демонстрационном режиме, без серверной авторизации и обмена сообщениями между пользователями.

Прототип сайта доступен на [darkseek.cyxap.top](https://darkseek.cyxap.top/).

## Для локального запуска выполните 


    node server.js


## Файлы проекта

- `index.html` - интерфейс и логика прототипа
- `style.css` - оформление и мобильная вёрстка
- `server.js` - HTTP-сервер для локального запуска
- `logo.png` - логотип Darkseek
- `CNAME` - домен проекта на GitHub Pages
