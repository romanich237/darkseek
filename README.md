# DarkSeek

Мессенджер для общения без номера телефона и электронной почты. Создайте профиль, сохраните личный ключ и поделитесь публичным ID, чтобы начать переписку.

## Как это работает

При создании профиля DarkSeek выдаёт ключ доступа из 16 символов. Он используется для входа в аккаунт. Для поиска собеседников у каждого профиля есть отдельный публичный ID.

Диалоги и сообщения сохраняются в базе данных и доступны после повторного входа. Интерфейс адаптирован для компьютеров и телефонов.

## Возможности

- Создание профиля и вход по личному ключу.
- Поиск собеседников по публичному ID.
- Личные сообщения с сохранением истории.
- Отдельные черновики для диалогов.
- Проверка и установка обновлений через меню в Windows.

## Запуск

Для работы потребуется Node.js 24 или новее.

```sh
git clone https://github.com/romanich237/darkseek.git
cd darkseek
node server.js
```

После запуска откройте http://localhost:3000.

Параметры сервера находятся в `config.json`. Профили и переписка хранятся в SQLite-файле `users.db`, который создаётся автоматически.

## Обновления

Запустите `update.bat` и выберите нужное действие. После установки обновлений перезапустите DarkSeek.

## Доступ к профилю

Сохраните личный ключ — он понадобится для следующего входа. Собеседникам передавайте публичный ID. Ключ хранится на сервере в виде хеша, текст сообщений — в открытом виде.
