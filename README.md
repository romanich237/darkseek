# DarkSeek

Мессенджер с входом по личному ключу и поиском собеседников по публичному ID. Работает на Node.js, хранит данные в SQLite и запускается одной командой.

## Возможности

- Создание профиля без номера телефона и электронной почты.
- Вход по личному ключу из 16 символов.
- Личные диалоги с сохранением истории сообщений.
- Адаптивный интерфейс для компьютеров и телефонов.

## Быстрый старт

Понадобится Node.js 24 или новее.

```sh
git clone https://github.com/romanich237/darkseek.git
cd darkseek
node server.js
```

Откройте http://127.0.0.1:3000, создайте профиль и сохраните ключ доступа. Для начала переписки найдите собеседника по его публичному ID.

## Настройка и данные

Адрес, порт и путь к базе задаются в `config.json`. По умолчанию сервер доступен на этом компьютере. База `users.db` создаётся автоматически при первом запуске.

Ключ доступа хранится в виде хеша. Сообщения хранятся в базе в открытом виде. Для резервной копии остановите сервер и скопируйте `users.db`.

## Обновления

В Windows запустите `update.bat` и выберите проверку или установку обновлений. После установки перезапустите сервер.
